How I built my portfolio with Claude Code

The useful part wasn’t asking AI to write more code. It was giving it a smaller, clearer system to reason inside — then reviewing each decision before it shipped.

01

What I built

A single-page portfolio for technical recruiters — built to lead with real numbers, not generic copy, and to make the engineering behind it visible.

The brief was intentionally focused: create a fast, legible surface for enterprise digital platforms, APIs, and cloud systems, then use the build itself as a case study in AI-assisted engineering.

Structure

Single page

One deliberate narrative instead of a maze of pages.

Discoverability

SEO & GEO

Structured data, a clear site map, and explicit crawler guidance.

Delivery

CI/CD

A repeatable path from a merged change to a live site.

Trust

Analytics

Enough signal to learn what works without tracking people around.

02

Tech stack

No framework, no server, no CMS. A small, legible surface is easier for both a person and an AI agent to understand correctly on the first try.

Frontend

Bootstrap + Sass

Utilities, components, design tokens, self-hosted Inter, and inline SVG icons.

Build tooling

Vite

Multi-page output, with the blog and homepage defined as explicit build entries.

Hosting

S3 + CloudFront

Private bucket, CDN delivery, Route 53, and ACM for DNS and TLS.

Automation

GitHub Actions

Build, sync, invalidate, and authenticate with IAM OIDC — no static AWS keys.

Site footer

Tech Lead building enterprise digital platforms, APIs, and cloud systems — with AI-assisted engineering as a delivery multiplier.
